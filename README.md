# Finite-element-based-algorithm-for-organ-growth-and-adaptation
Finite element algorithm for surface growth and adaptation of biological tissues. Computes the boundary node displacements that achieve prescribed volume changes in surface elements via a Moore-Penrose pseudoinverse. Modular and independent of the growth law. The main file (Main.m) is commented. 

Please cite the paper "Finite element-based algorithm for organ growth and adaptation with application to bone modelling. Manchado-Morales, P., Martínez-Reina, J., Castoldi, N.M, Pivonka, P. & Calvo-Gallego, J.L. International Journal for Numerical Methods in Biomedical Engineering (2026)
